# Fashion-MNIST Image Classification using ANN and CNN

## Project Overview

This project explores deep learning approaches for image classification using the Fashion-MNIST dataset. It compares an Artificial Neural Network (ANN/MLP) with a Convolutional Neural Network (CNN) to evaluate their ability to recognise different clothing categories.

## Dataset

Fashion-MNIST contains 70,000 grayscale images across 10 clothing categories, with 60,000 training images and 10,000 test images. Each image has a resolution of 28 × 28 pixels.

## Technologies Used

- Python
- PyTorch and Torchvision
- NumPy and pandas
- Matplotlib and Seaborn
- Scikit-learn

## Methodology

1. Load and preprocess the Fashion-MNIST dataset.
2. Develop an ANN using fully connected layers.
3. Develop a CNN using convolutional and pooling layers.
4. Train both models using the Adam optimiser and cross-entropy loss.
5. Compare model performance using accuracy, loss curves and classification metrics.
6. Evaluate predictions using a confusion matrix and sample images.

## Project Findings

The experiments compare the classification performance of ANN and CNN architectures. The project report identifies the CNN as achieving better validation and test accuracy than the ANN, demonstrating the value of spatial feature extraction for image classification.
